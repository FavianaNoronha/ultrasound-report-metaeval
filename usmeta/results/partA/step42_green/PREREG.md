# Step 42 pre-registration: GREEN (4-bit) on a Colab T4, added to the Step 33 factorial and the Step 35 limit of detection

Status: written and committed BEFORE any GREEN score exists (Step 37 could not run GREEN on the 16 GB Mac). The pair list was exported first (SHA-256 of `local_data/step42/green_pairs.jsonl`: `3807ae9453021c054cf6b0f84b24800dbeafc89f87fae445f8ec7ca3f185a937`; 4,088 pairs in 320 units); nothing in it depends on any score. Deviations after this commit are listed in `results.md`.

## What is scored
- **Model: `StanfordAIMI/GREEN-radllama2-7b` loaded in 4-bit** (bitsandbytes NF4, float16 compute) because a T4 has 15 GB. **Every result is labelled "GREEN (4-bit)"; it is not the official fp16 GREEN** and no equivalence check against fp16 was possible. Package: `Stanford-AIMI/GREEN` from GitHub (prompt, generation settings and parsing unchanged: greedy, max length 2048, batch 8, 4 if memory runs out; the GREEN score = matched findings / (matched findings + clinically significant errors), 0 if no matched finding, missing if the analysis cannot be parsed). Only the model loading is patched (4-bit instead of fp16).
- **Text:** templated only (the Step 33 factorial blocks and the Step 35 candidates, both saved earlier; no new test-split read). **No HiSBreast text** is in the pair file or leaves the machine. The file uploaded to Colab holds only `id`, `reference`, `candidate`; the key that maps ids to roles / cases / datasets stays local (`pair_key.json`).

## Sample (stratified, ordered, nested; seed 0)
- **F units (factorial):** a case of one of 8 breast / thyroid datasets (BrEaST, BUS-BRA, BUSI, UDIAT, BUS-UCLM, TN3K, TN5000, DDTI; up to 20 each) with 2 small / matched rewordings (a), the 2 large rewordings (b: terse, long), 3 planted errors (c) and the same 3 errors in both large styles (d: 6 texts) = 13 pairs, giving 6 blocks.
- **L units (limit of detection):** a case of one of the 4 Step 35 cells (breast size in mm, breast size in % width, thyroid size in % width, fetal-head HC; up to 40 each) with up to 2 matched synonyms and all of its Step 35 error candidates (both directions, every level).
- **Order:** F and L alternate; inside F the datasets round-robin, inside L the cells round-robin, inside a stratum a seeded shuffle. Any prefix of the order is balanced across strata. Design size 320 units (160 F + 160 L), 4,088 pairs.
- **Size rule (the n, fixed by a rule because it needs the T4 timing):** the notebook first times 20 dev pairs (templated dev text) on the T4, takes s = 1.1 x the measured seconds per pair, and sets **n_units = the largest prefix of the order whose pairs x s <= 10,000 s (about 3 h)**, at least 40 units, at most all 320. It writes `n_chosen.json` (n, pairs, s, timestamp) **before the first test pair is scored**; the analysis uses only complete units of that prefix. A hard stop at 11,000 s of scoring keeps the run inside about 3 h; scores are saved after every batch and a disconnected run resumes from the last saved id (a prefix completed at the stop is used, and the shortfall is reported).

## Analyses (identical to Steps 33 and 35; group bootstrap 1,000, seed 0; under 30 groups: "too small", not compared)
- **Factorial (as Step 33):** per F unit, for each of the 3 errors x 2 styles (a block), the four cell scores a (mean of the unit's 2 small / matched pairs), b (large rewording of that style), c (error, small edit), d (same error, large edit); blocks with any missing cell are dropped (counted). Two-way variance share of fact (error vs none) and wording (small vs large) with interaction and residual, pooled breast + thyroid (primary), per organ, bootstrap over case groups. **Decision rule (as pre-registered for Step 33): GREEN (4-bit) is "fact-driven" iff eta-squared(fact) > eta-squared(wording), pooled.** AUROC at matched wording (c vs a, d vs b) and both reversal rates (d below a; c above b) reported.
- **Limit of detection (as Step 35):** per cell and level (relative size error 5, 10, 20, 25, 30, 50, 100%; HC shifts 1, 2, 5, 10, 20 mm, both directions pooled), per-case AUROC of the errors at that level vs the case's matched synonyms (ties 0.5); **limit of detection = the smallest level with AUROC >= 0.80**, CI = percentiles of the same rule over bootstrap resamples (">max" if never).
- **Comparison (descriptive, no hypothesis test):** next to the saved Step 33 / 35 / 37 numbers for the judge, RadGraph-F1 and the word scorers (different, larger or capped samples; stated), with the verdict lines first: fact-driven or wording-driven, the limit of detection per cell, and whether GREEN (4-bit) reaches the judge's fact share (0.68) or the judge's limits (5% size, 1 mm HC) on cells with 30 or more groups.

## Caveats fixed in advance
4-bit quantisation may change GREEN's behaviour (not checked); templated text only; a capped sample (the realised n is whatever the T4 time allows, perhaps well below the design size, so per-cell group counts may be under 30); GREEN was built for chest-X-ray reports (as RadGraph); one run, greedy; Colab hardware and package versions are recorded by the notebook (`colab_env.json`).
