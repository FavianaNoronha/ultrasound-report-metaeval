# Step 34 pre-registration (written and committed BEFORE any Step 34 test-split score exists)

Status when written: no Step 34 feature, model or test score has been computed. The test split is not touched until this file is committed. Deviations after commit will be stated in `results.md` under "Deviations from the pre-registration".

## Hypotheses (verbatim from the brief)
- **H1:** on breast + thyroid, hybrid AUROC vs large harmless rewordings >= best single scorer + 0.05.
- **H2:** hybrid AUROC vs large rewordings is within 0.05 of its AUROC vs matched one-word rewordings (wording invariance); the judge alone is not.
- **H3:** on Step 28/32 writer reports with hand-checked labels, hybrid AUROC > every single scorer (exploratory if fewer than 30 wrong reports). If the Step 32 hand check is not filled yet, H1 and H2 are run and H3 is left as "pending hand check" without touching those test reports.

## Operational definitions (fixed now)
- **Single scorers compared:** BLEU, ROUGE-L, chrF, BERTScore, RaTEScore, Gemma `judge_score`, Gemma `sentence_f1`, `llm_finding_f1`, and the Step 29 U-Net image check alone. The regex `finding_f1` (reads our template) and the oracle-box MedSAM check (given the true box) are shown for reference but are **excluded from "best single scorer"** because they are circular or oracle. "Best single scorer" = the highest AUROC vs large harmless on the breast + thyroid pooled test set among the compared ones.
- **AUROC:** per case, error candidates vs the harmless rewordings of one group (small / matched / large) of the same reference, ties 0.5, mean over cases; 95% CI by group bootstrap (1,000 resamples, seed 0). Cells under 30 groups: "too small to compare".
- **H1 supported** iff the pooled breast + thyroid point estimate satisfies hybrid >= best single + 0.05 (the paired-bootstrap CI of the difference is reported and a lower bound <= 0 is stated). **Not supported** otherwise. A ceiling effect (best single already above 0.95) is stated but does not change the verdict.
- **H2 supported** iff |AUROC(large) - AUROC(matched)| <= 0.05 for the hybrid on breast + thyroid pooled **and** on breast and thyroid separately, **and** the same difference for `judge_score` alone is > 0.05 on the pooled set. Otherwise not supported.
- **H3:** evaluated only when `docs/step32_check.csv` is filled and the wrong-report class has at least 30 reports (else labelled exploratory); until then "pending hand check", no scores of the Step 28/32 reports are computed.

## Hybrid (fixed now)
- **Features** (per reference-candidate pair): (1) `judge_score` (Gemma, prompt_v2, saved); (2) `llm_finding_f1` with **extractor v3 if the Step 32 dev/val check passed (field agreement >= 0.98 pooled and per organ on both dev and val), otherwise extractor v2** (Step 27); (3) image-check **position credit** and (4) image-check **size credit** from the Step 29 label-free U-Net masks, with the frozen Step 20 tolerance-aware rule (tau 0.3, adjacent position), one credit per claim type read from the candidate text. When the image check cannot assess a claim (the candidate states no position / no size, there is no scan, or the predicted mask is empty), the feature is **missing**: its value is set to the neutral 1.0 and a missing-indicator (1 = missing) is added for position and for size; it is never set to 0. Fetal head: same features with the Step 29b **exact** head-circumference rule in place of position and size (HC18 only; FetalHead has no pixel size, so that feature is missing with an indicator), fitted and reported separately.
- **Model:** L2-regularised logistic regression (scikit-learn, standardised features, `class_weight='balanced'`, fixed seed 0) predicting "planted error" (1) vs "not an error" (0: all harmless rewordings and identical copies); score = 1 - P(error), so lower = error, as for every scorer. One model for breast + thyroid with an organ indicator; one for fetal head.
- **Fit on DEV, tune on VAL:** training rows = dev-split benchmark candidates of the dev-era judge sample (rows that have a saved Gemma judge score); the regularisation strength C in {0.01, 0.1, 1, 10} is chosen on the VAL rows (judge sample restricted to the val split) by mean AUROC over small / matched / large harmless. Feature definitions and C are then frozen. The U-Net was trained on dev images, so its dev image-check features are in-sample (optimistic); val features are out-of-sample. This is stated as a limitation, not corrected.
- **Non-learned baseline:** the minimum over the **available** (non-missing) scores among `judge_score`, `llm_finding_f1`, image position credit, image size credit. Reported next to the hybrid so a gain is not just fitting.
- **Test (once):** the judged test subset (59 cases per dataset) for breast and thyroid (and HC18 / FetalHead for the fetal-head model); U-Net inference on those cases' images; one logged `splits.load('test')`. Outputs: AUROC per organ x harmless group, correct-report score (mean hybrid score of the identical copies), per-error-type paired preference (strict share of error-vs-harmless pairs with the error scored lower, by the benchmark `category` field), each side by side with every single scorer. If extractor v3 is chosen and re-extracting the test texts would exceed 3 h, extraction runs in resumable chunks across runs (no case cap).
- **Reported as supported / not supported exactly as above**, with the numbers, even if the answer is negative.
